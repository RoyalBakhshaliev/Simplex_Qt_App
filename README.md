# 🖥️ Simplex Qt App (Linear Programming GUI)

Графическое десктопное приложение на C++ и фреймворке Qt для визуализации и решения задач линейного программирования симплекс-методом.

## 📌 Описание проекта
Проект представляет собой удобный инструмент с графическим интерфейсом (GUI) для автоматизации расчетов оптимальных производственных планов. Пользователь может задавать параметры задачи, после чего приложение производит расчеты и выводит пошаговые результаты.

## 🛠️ Стек технологий
* **Язык программирования:** C++ (ООП)
* **Интерфейс:** Qt Framework (GUI, сигналы и слоты)
* **Алгоритмы:** Симплекс-метод, матричные вычисления, обработка пользовательского ввода

## 🚀 Основные возможности
* Интерактивный ввод исходных данных задачи (ограничения, целевая функция).
* Пошаговое отображение симплекс-таблиц.
* Удобный оконный интерфейс, кроссплатформенность (Qt).
